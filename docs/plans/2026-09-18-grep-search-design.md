# grep 日志数据源 简化搜索扩展

用户已确认简化语法，并指定交付浏览器扩展。第一版支持 Chrome/Edge Manifest V3，在 logs.example.com 的 Explore 页面展示独立浮层。

- 空白分词代表 AND，`-debug` 代表排除，双引号合并短语；不增加 OR 等未确认的服务端语法。
- 从当前 URL 的旧版 `left` 数组读取时间、数据源、queryText；只替换第一个查询的 expr/value，完整保留其他字段、右侧查询和组织 ID。
- 生成可见查询预览，Enter 跳转到更新后的 Explore URL。无有效查询上下文时明确提示先在原页面选择环境、服务并执行一次查询。
- 使用 Shadow DOM 隔离样式，无外部依赖、无后台服务、无日志抓取、无凭证权限，不持久化检索词。
- 只支持已知旧版 URL 结构；遇到无法识别的查询必须报错，不猜测环境或数据源。
- 用 Node 原生测试验证语法和 URL 保留，用本地模拟页面验证交互。真实站点当前连接失败；实际后端对引号/grep 的解释必须在目标站点验收。

交付：可加载的扩展目录、ZIP、中文说明、本地演示页和测试。
